# Fuel Run

## 概要
燃料を回収しながらゴールを目指す縦スクロール型レースゲームです。

## 使用技術
- C++
- DX ライブラリ
- Visual Studio

## 操作方法
- マウス操作

## 実装した機能
- プレイヤー操作
- 敵車生成
- 燃料システム
- スコア管理
- ステージ制
- シーン遷移

## 工夫した点
- ソースコードの分割
- ステージ制の導入
- ステージごとのクリア条件追加

## ステージ構成
- Stage 1：チュートリアル
- Stage 2：タイムアタック
- Stage 3：スコアアタック
